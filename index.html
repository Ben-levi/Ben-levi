Problems I've actually shipped

Four projects, each one built, deployed and operated by me. Problem, what I built, and how it runs in production.

client project · WhatsApp automation

WhatsApp booking assistant

Problem: a bridal & event makeup business handled every inquiry, artist match and reminder by hand on WhatsApp.

  • Hebrew WhatsApp receptionist that classifies each inquiry and routes it — bride, escort or evening client
  • Checks every artist's Google Calendar and ranks the crew by area, group size and style from a questionnaire
  • Hands closed deals to the office manager, then sends T-14 / T-5 / T-1 reminders and a review request
  • Deterministic rules from the client's spec — no LLM guessing in the loop
  • Ops: CI (typecheck, lint, tests), post-deploy smoke checks, health probes, error beacon, weekly backups, written runbook

serverless · finops

CostGuardian

Problem: AWS bills surprise you after the fact. I wanted alerts — and optional automatic action — before they do.

  • EventBridge-scheduled Lambda pulls spend from Cost Explorer and stores history in DynamoDB
  • SNS alerts on threshold breach, with cooldown to avoid alert spam
  • Optional enforcement stops tagged EC2 instances, behind dry-run and "armed" safety switches, with an audit log
  • Deployed with AWS CDK from GitHub Actions via OIDC, gated by a production environment

Small Business CRM

Problem: small businesses need a simple place to track customers, orders and inbound leads — without paying for a big CRM.

  • Serverless API on Vercel with a Neon Postgres database
  • JWT login with bcrypt-hashed passwords; customers and orders management
  • Public contact form with Cloudflare Turnstile spam protection and email notifications via Resend
  • Error tracking with Sentry

06 · architecture

How this site is designed to run

The target platform fits in the AWS free tier and deploys from a single git push: GitHub Actions assumes an AWS role via OIDC, so no long-lived keys exist anywhere. Status today: the site is served from GitHub Pages; the AWS stack below is written in Terraform and validated in CI, ready to apply.

Everything is defined in Terraform and deployed by GitHub Actions. Monthly cost target: < $1 (free tier + a few cents of LLM tokens). An AWS Budget alarm emails me before it can ever exceed $5 — cost is an SLO here.
